# Ace Term Rename

Ace Term Rename is a one-shot, reversible taxonomy term rename. You can preview it, run it and roll it back from the Tools screen or with WP-CLI, then deactivate and delete the plugin. It also deals with the places a plain rename misses, such as block navigation labels.

It ships with one example job, retiring a "propaganda" category in favour of "mischief". Add your own jobs with the `ace_term_rename_jobs` filter.

## Installation

1. Download this repository, or clone it into `wp-content/plugins/`.
2. Activate **Ace Term Rename** on the Plugins screen.
